## Voice & Tone

lossy is deadpan absurdist. It presents a fundamentally silly idea — compressing video through natural language — with the seriousness of real engineering. The humour comes from the gap between the rigorous framing ("codec", "compression ratio", "reconstruction") and the obviously terrible results.

- **Technical but self-aware** — use real signal processing and codec terminology, but acknowledge the joke.
- **Curious, not ironic** — the project is genuinely interested in what survives the round-trip. The comedy is a vehicle for real observation.
- **Show, don't explain** — let the mangled output speak for itself. Side-by-side comparisons are funnier than commentary.

## Name

"lossy" — a direct reference to lossy compression. The name works because every codec is lossy to some degree; this one just happens to lose almost everything. Lowercase, no article.

## Blog Post Identity

The output is a Weird Software blog post. It should read like a project log from someone who built something they knew was pointless but did it thoroughly anyway. Structure: motivation, approach, results, reflection. Screenshots and video clips throughout.

## Visual Style

No custom branding needed — this is a one-off experiment, not a product. Any visual assets (diagrams, comparison frames) should be functional and minimal.
